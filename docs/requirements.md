## Como revisar sem depender de alegações

Execute `npm ci`, `npm run check` e `npm run test:e2e`. Consulte os relatórios e repita o Lighthouse na URL publicada. Os serviços desta produção já foram ativados; consulte docs/activation.md para a evidência real. Para outra instalação, use docs/setup.md. Não considere mocks prova de entrega de e-mail ou de execução de RLS.
