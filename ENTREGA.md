O historico-git.bundle incluído conserva os commits e branches. Para recuperar: git clone historico-git.bundle portfolio-historico. O GitHub público também mantém o histórico. Nenhuma senha, chave real, sessão, node_modules ou arquivo .env real é distribuído.
